# Task Manager API

REST API for managing tasks built with Node.js, Express, and MongoDB.

## Live API
https://task-manager-backend-33pj.onrender.com

## Endpoints

GET /api/tasks  
POST /api/tasks  
PUT /api/tasks/:id  
DELETE /api/tasks/:id  

## Tech Stack

Node.js  
Express.js  
MongoDB  
REST API  
Render Deployment
